# v0.5 — Automatic directives and crisis updates

The current play loop supersedes the v0.4 editing/Office approval/Bank funding screens:

**Write once → Submit directive → Ready → Advance month → Read results.**

Submission is funding authorization. The interpreter makes and records assumptions without asking clarification questions. Server validation reserves dollars, oil, fuel and group commitments automatically. Each unsupported or impossible clause has a failure report; valid clauses remain eligible. No execution happens in the analysis preview. Only committed monthly settlement changes inventories and pays action costs. The original submission is retained as one directive, including any failures.

Costs, troop availability, territorial adjacency, building prerequisites, conditions and counterparty consent remain authoritative. Submissions cannot create money, foreign consent or nonexistent game mechanics. Preview validation is sequential inside a directive; already committed forces and resources cannot be spent twice. Diplomatic consent pending from another government is reported as pending rather than completed. Official proposals cost $5; transfer dollars are paid only upon activation with both parties' consent and sufficient resources. A failed military action reports why it failed; attacks report their actual final outcome.

## Five views

- Map: stable lightweight map, owner-visible forces, dated scouting and world news.
- Presidential Office: the only directive composer, one submitted version, assumptions, explicit scheduled actions and private monthly results. War shortcuts prefill this composer.
- Bank: automatic commitments, available cash, paid ledger, loans and upkeep; no second approval.
- Foreign Affairs: chat with humans or live AI, contextual negotiation fallback, Submit agreement and Accept agreement. Both buttons queue directives rather than performing transfers from chat.
- Public Announcements: permanent monthly crisis updates based on committed state. Major developments display first; smaller government developments and national situation tables expand on demand. Projects name locations, cost and upkeep; policies state actual game-index effects; wars, battles and agreements state recorded outcomes. Private movement counts, scouting reports, intelligence-policy purposes and conversations are excluded.

## AI configuration

Copy `.env.example` to `.env` and configure `OPENAI_API_KEY` and `OPENAI_MODEL` locally. Restart `npm start`; `.env` now loads automatically. Never place keys in frontend code or commit them. Environment variables already provided to the process take precedence. No provider subscription or API key is supplied by this repository.

A configured provider interprets narrative directives, drafts official communication from the directive request and generates conversational diplomatic responses from the last 30 messages, public situation and bilateral agreements. Server rules still validate plans and prices. Provider failures fall back transparently. Without credentials, the visible local interpreter covers common actions, inferred routes/default budgets, natural message requests and treaty proposals; it cannot interpret every imaginable directive. The local diplomat produces amount/duration-specific counteroffers and refers to prior offers; it is explicitly labeled as a local negotiator rather than live AI.

Crisis-update presentation is inspired by the MUN directive/consequence cycle (https://munuc.org/crisis/). This is a fictional rules-based simulation, not a reproduction of a third-party game or an unrestricted world simulator. Existing advanced matches remain preserved; old simplified matches gain this workflow for new directives. Older unfunded drafts should be resubmitted if wanted; they are not silently authorized.
