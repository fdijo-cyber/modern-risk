# Development roadmap

The current delivery is an executable vertical slice spanning several original phases; no original phase is claimed fully complete.

1. **Playable foundation:** finish production identity, save/restore UI, geographic map and synchronized reconnect UX. Acceptance: two separate devices finish a persisted match with no hidden-state exposure.
2. **National systems:** expand budgets/resources/production, tax feedback, administrative costs and complete directive audit IDs. Acceptance: ledger reconciles every expenditure and all material flows.
3. **Warfare:** named formations, reserves, ground/air/naval catalog, route capacity, supply classes, maintenance and contested simultaneous operations. Acceptance: conservation and casualty/property tests across randomized scenarios.
4. **Diplomacy/AI:** richer relations/contracts, autonomous diplomatic proposals, utility scores, distinct difficulty parameters, versioned structured LLM adapters and deterministic fallback. Acceptance: no illegal AI resource creation or classified leakage.
5. **Intelligence/news:** covert abstractions, observations, eight-part briefings, cartoon anchors, event animations and optional narration. Acceptance: public news derives only from public committed events.
6. **Release:** sustained early victory, statistical balance tests, tablet/browser E2E, PostgreSQL workers, load/security review and monitored hosted deployment. Acceptance: clean restore, multi-client tests, tested backups and all original section-28 scenarios.

GitHub issue/milestone creation will follow repository access. Keep this roadmap and progress.md synchronized with verified behavior, not UI presence.
